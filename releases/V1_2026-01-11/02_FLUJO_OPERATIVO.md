# Flujo operativo del sistema

1. Abrir archivo de la locación
2. Habilitar macros
3. Seleccionar periodo
4. Validar empleados cargados
5. Agregar empleado (solo si no existe)
6. Editar incidencia para capturar incidencias reales
7. Usar “Completar incidencias”
8. Revisar información
9. Cerrar periodo
