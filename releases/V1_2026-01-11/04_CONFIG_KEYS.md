# Configuración (tblConfig)

## Keys principales

- MasterDBPath  
  Ruta raíz de REPORTES GERENTES

- EmployeeDBPath  
  Ruta completa al archivo de empleados

- EmployeeDBTable  
  Tabla de empleados (ej. tblEmpleados)

- IsTemplate  
  1 = template / 0 = archivo de locación

- IsTestFile  
  Marca de prueba

- LockWindowHours  
  Ventana de edición antes de bloqueo

- LockPassword  
  Password de protección
